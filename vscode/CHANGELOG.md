# Changelog

## 0.1.0 — first release

- Chat: a side-panel webview with streaming markdown, a card per tool call,
  and the questions Vesna asks as buttons.
- Garden: a tree view of the spec's stages, tasks and witnesses, each node
  opening the document or brief behind it.
- Findings: review findings as diagnostics — squiggles on the lines they
  name, entries in the Problems panel.
- Status bar: the current mode, click to cycle `plan → ask → auto`.
- Commands: New/Open/Approve Spec, Approve Plan, Build, Cancel Build,
  Restart Server, Open spec.md/plan.md, Show Panel.
